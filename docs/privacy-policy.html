Privacy Policy — Liquid Files

Package ID: com.aistudio.liquidfiles.vxtrnq • Minimum Android: 8.0 (API 26) • Effective Date: 2026-01-01

1. Overview

Liquid Files is an on-device file manager, media/PDF viewer, storage analyzer, and encrypted file vault for Android. Your personal files, folders, media, and Safe Vault contents remain strictly on your device. Liquid Files does not upload your personal files or Vault contents to external developer servers.

2. On-Device File & Storage Access

  • Storage Access: Storage permissions (MANAGE_EXTERNAL_STORAGE, legacy storage on Android 8–12, scoped media permissions on Android 13+, and Storage Access Framework) are used solely to let you browse, search, copy, move, rename, inspect, optimize, share, and delete files you select on your device and removable SD card.
  • Local Metadata: Favorites, Recycle Bin metadata, and Vault file records are stored locally in the app's private database and excluded from device/cloud backups (android:allowBackup="false").

3. Safe Vault Encryption & Biometric Authentication

  • Vault files are encrypted locally using streaming AES-256-GCM with a high-entropy key wrapped by Android Keystore hardware security.
  • Your 4-digit Vault PIN and optional recovery answer are stored locally only as salted PBKDF2-HMAC-SHA256 hashes—plaintext credentials are never stored or transmitted.
  • Optional biometric unlock uses Android's official BiometricPrompt API. Biometric data never leaves secure OS hardware and cannot be read by Liquid Files.

4. Google AdMob & User Messaging Platform (UMP)

Liquid Files displays non-intrusive Google AdMob banner, native, and strictly rate-limited interstitial ads outside Safe Vault and file-operation dialogs. When initialized with user consent (via Google UMP where required by law), the Google Mobile Ads SDK may collect:

  • Advertising ID (AD_ID) and device identifiers (subject to OS tracking controls and UMP consent)
  • Approximate location derived from IP address
  • App interactions (ad impressions and clicks) and SDK performance/crash diagnostics

You can update or withdraw consent choices anytime inside Settings → Manage Ad Privacy Choices or in Android Settings → Privacy → Ads. Learn more in the Google Privacy Policy.

5. Local Wi-Fi File Portal

When you manually enable Wi-Fi Share, Liquid Files starts a temporary local HTTP server restricted to your local Wi-Fi network (LAN) with strict path checks blocking Safe Vault, databases, and private directories.

6. Children's Privacy

Liquid Files is not directed at children under 13 (or equivalent age in your jurisdiction) and does not knowingly collect personal information from children.
